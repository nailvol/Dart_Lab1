Ответы на вопросы
Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
В Dart тип переменной известен на этапе компиляции, и компилятор проверяет его до запуска. В Python тип определяется в рантайме. Преимущество: целый класс ошибок (например, присвоение строки в int) ловится заранее, а не при выполнении.

Что означает String?? Чем отличается от String?
String — переменная гарантированно не может быть null. String? — nullable-тип, может содержать null. Перед вызовом методов нужна проверка или операторы ?. / !.

Зачем в Dart final, если в Python можно просто договориться не менять переменную?
final — это гарантия на уровне компилятора. В Python «договорённость» можно случайно нарушить, и ошибка не будет замечена. В Dart попытка изменить final-переменную — ошибка компиляции.

Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
Именованный параметр передаётся по имени и заключается в {}. required делает его обязательным. Позиционный передаётся по порядку.
Пример: describePet(name: 'Барсик', age: 3);
